Hi, 你好，我是贺煦修。

这个博客写的是我自己动手折腾的记录，内容大多从我在 NodeLoc 论坛的帖子同步过来。

本博客的特色：

- **第一手，不是搬运。** 写的东西都是自己做的：搭的 API 服务（TokenTokenBond、M365-Copilot2API）、从头训练的小模型（Prochlo-190M）、给打印机装驱动。出了什么问题、怎么查的、最后怎么解决的，都写下来。
- **数字说话。** 结论尽量带着实测：模型延迟一张表、假期跑了 52.1 亿 token、270 GB 数据洗成 220 GB。感觉不算数，测出来的才算。
- **失败也写。** 磁盘被日志写满的事故复盘、跑了 165 次却什么都没干的运维 agent、开不开源的纠结——翻车和拿不准的事同样记录。
- **链条完整。** 从下载数据、清洗数据，到训练模型，再到部署服务和运维复盘，一个人把全流程走完。
- **社区味。** 很多内容长在 NodeLoc 社区里：看板娘 Enna、社区能量的价值分析。博客是社区生活的延伸。
