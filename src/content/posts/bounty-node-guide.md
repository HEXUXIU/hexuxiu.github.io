欢迎来到 **赏金计划（Bounties）** 节点！🎯⚡

这里是**有偿供需对接的技术集市**，也是**极客一较高下的竞技擂台**。你有资源与痛点，我有技术与方案。为保障雇主委托快速落地、猎人权益不受侵害，请在发帖与接单前仔细阅读本规范。

## 一、 发帖规范与标签流转 🏷️

为保持版面整洁并让有效信息第一时间被检索，发帖须严格配合**论坛自带标签（Tags）与标准标题文本**。

### 1. 必选论坛标签（Tags）

发帖时，请在编辑器中勾选以下两类标签：

- **任务类型标签（二选一）**：`悬赏` / `赏金大赛`
- **状态进度标签（随进度修改）**：`悬赏中` 🟢 / `进行中` 🟡 / `已结算` 🔵 / `已关闭` 🔴

### 2. 标题文本格式

剔除分类与状态后，标题输入框只需遵循以下格式：

> **`[奖励标的] 核心需求或赛题一句话概括`**

- **明确标价，拒绝画饼**：奖励标的必须直白清晰，拒绝使用“私聊/面议/福利”等模糊词汇 。
- **标准标题示例**：
  - *现金类*：`[￥300] 解决 Go 网关高并发下的连接池泄漏问题`
  - *资源类*：`[美西大盘鸡1年] 编写一套容器自动灾备与异地同步 Shell 脚本`
  - *社区类*：`[8000能量 +「神级逆向」专属称号] 第一届轻量模型评测跑分竞技赛`

## 二、 模式运行细则

本节点运行 **「单人定向悬赏」** 与 **「赏金竞技大赛」** 双轨制，玩法各有侧重：

| **维度** | **定向悬赏（先到先得/单人锁单） 🎯** | **赏金大赛（公开打擂/赛马） 🏆** |
|---|---|---|
| **适用场景** | Bug 排查、特定脚本开发、协议逆向、运维排障 | 算法精度 PK、性能压测打榜、主题设计、轻量 Hackathon |
| **执行机制** | 双方谈妥后，楼主**必须将状态标签改为 `进行中` 并指定接单人**，避免多位猎人同时投入白费精力。 | 全员自由提交，设定公开评选指标与打榜截止时间。 |
| **成果验收** | 达到楼主约定的验收准则即全额结算。 | 设立评测脚本/排行榜/公示期，按综合名次瓜分奖池。 |

## 三、 奖励兑现与交易安全

### 1. 奖励承诺不可空头支票

- **虚拟资源类（VPS / 算力 / 账号）**：发帖时必须注明规格详情、剩余有效期及转让方式（如：官方账号 Push、转绑邮箱或提供独享凭证）。
- **社区资产类（能量 / 虚拟称号）**：发帖前请确认自身账户具有足额能量，或已提前向管理团队报备赛事专属称号权限 🎖️。
- **现金结算类**：明确结算通道，不得在交付后要求变更成折价物品 。

### 2. 防“白嫖”与防欺诈机制

- **核心代码保护**：猎人交付成果前，建议通过脱敏日志、录屏视频、线上 API 测试 Demo 等形式自证功能，待收到款项/资源转让后再交付全部未混淆源码 。
- **白嫖严惩**：严禁发帖人以“方案试测”、“提供思路”为由私自套取成果后单方面关闭悬赏。一经取证核实，直接**永久封禁账号并通报黑名单** 。
- **里程碑拆分**：大额项目强烈建议拆分阶段验收分批兑现，降低双方履约风险 。

## 四、 免责声明与红线准则

1. **平台撮合免责**：本节点仅提供技术竞技、需求对接与交流空间。**社区不承担任何交易双方的资金担保、信用托管或线下违约连带责任**，请自行评估交易风险 。
2. **严禁黑灰产与破坏性行为**：严禁发布任何木马免杀、未授权系统渗透、抓取涉及个人隐私的敏感数据、盗号及任何触犯当地法律法规的任务。违规内容秒删封号，情节恶劣者配合有关部门追责 。
